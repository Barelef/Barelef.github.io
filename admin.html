Панель управления галереей

Добавляйте, редактируйте и удаляйте работы. Панель работает офлайн, список хранится в вашем браузере. Когда закончите — нажмите «Скачать manifest.json» и загрузите файл на GitHub (заменить старый).

Как опубликовать изменения: 1) скачайте manifest.json кнопкой ниже; 2) на GitHub: Add file → Upload files → выберите manifest.json (и картинки работ, если добавили новые) → Commit changes; 3) через 1–2 минуты галерея на сайте обновится. Имена картинок — только латиницей, без пробелов (например peony_white.jpg).
