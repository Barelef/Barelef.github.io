# Сайт-портфолио: Ботанический барельеф Ольги Завьяловой

Бесплатный статический сайт для GitHub Pages.

## Состав архива
- index.html   — сам сайт (галерея, обо мне, мастер-классы, контакты)
- admin.html   — панель управления каталогом работ
- manifest.json — каталог работ (уже заполнен работами со страницы ВК)
- img/         — картинки работ (сейчас стоят заглушки — замените своими)

## Публикация на GitHub Pages (бесплатно)
1. Зарегистрируйтесь на github.com.
2. Создайте репозиторий с именем `ваш_логин.github.io`.
3. Нажмите Add file → Upload files и загрузите ВСЕ файлы из этого архива
   (index.html, admin.html, manifest.json и все картинки из img/ — можно сохранить структуру).
4. Settings → Pages → Source: ветка main → Save.
5. Через 1–2 минуты сайт откроется по адресу https://ваш_логин.github.io

## Как обновлять галерею
1. Откройте admin.html двойным кликом (работает офлайн, в любом браузере).
2. Добавьте/удалите работу, заполните название, размер, цену, категорию.
   В поле «Файл картинки» укажите имя файла из папки img/, например img/panno_les.jpg
3. Загрузите НОВЫЕ картинки в папку img на GitHub (Add file → Upload files).
4. Нажмите «Скачать manifest.json» и загрузите его на GitHub вместо старого (Add file → Upload files → Commit changes).

## Замена картинок
Картинка на сайте — это файл в папке img/. Чтобы заменить заглушку:
- загрузите своё фото с тем же именем файла (например img/diptyh.jpg), либо
- загрузите под новым именем и укажите его в admin.html.
