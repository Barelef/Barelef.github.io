# Ботанический барельеф — сайт художника

## Публикация на GitHub Pages (бесплатно, навсегда)

1. Зарегистрируйтесь на github.com (кнопка **Sign up**). Логин станет адресом сайта: `логин.github.io`.
2. Нажмите **+** (правый верхний угол) → **New repository**.
3. Имя репозитория: строго `ваш_логин.github.io` (например, `slavianka-art.github.io`). Галочка **Public** → **Create repository**.
4. На странице репозитория: **Add file → Upload files** (или ссылка "uploading an existing file").
5. Перетащите ВСЁ содержимое этой папки: `index.html`, `admin.html`, `manifest.json`, `README.md` и папку `img` целиком. Нажмите **Commit changes**.
6. **Settings** → слева **Pages** → Build and deployment: Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)** → **Save**.
7. Через 1–3 минуты сайт откроется по адресу `https://ваш_логин.github.io`.

## Фотография автора

1. Возьмите портрет (лучше квадратный, примерно 800×800 пикселей).
2. Переименуйте файл в `author.jpg` (маленькими буквами).
3. На GitHub откройте папку `img` → **Add file → Upload files** → загрузите `author.jpg` → **Commit changes**.
4. Через минуту фото появится в разделе «Обо мне» в круглой рамке. До загрузки там показывается заглушка «ОЗ».

## Обновление галереи работ

1. Откройте `admin.html` двойным кликом (работает офлайн, в браузере).
2. Добавляйте / редактируйте / удаляйте работы, меняйте порядок кнопками ↑ ↓.
3. Новые картинки работ загрузите на GitHub в папку `img` (имена латиницей, без пробелов).
4. Нажмите **«Скачать manifest.json»** и загрузите этот файл на GitHub с заменой (Add file → Upload files → Commit changes).
5. Через 1–2 минуты обновлённая галерея появится на сайте.

## Правила имён файлов

Только латинские буквы, цифры и дефис: `peony_white.jpg`, а не «пион белый.jpg».

## Структура

- `index.html` — сам сайт (галерея с фильтрами, лайтбокс, «Обо мне», мастер-классы, контакты)
- `admin.html` — панель управления галереей
- `manifest.json` — каталог работ (его обновляет панель)
- `img/` — фотографии: `author.jpg` + фото работ из каталога
